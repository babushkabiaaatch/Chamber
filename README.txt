Saiyan Chamber - setup (no folders needed)
Quick use: just double-click index.html. It works offline in any browser.

To install it like an app on your phone:
1. Create a NEW public GitHub repo (e.g. "chamber") and upload these 5 files to its root:
   index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png
2. Settings > Pages > Deploy from a branch > main, / (root) > Save. Wait 1-2 minutes.
3. Open https://YOUR-USERNAME.github.io/chamber/ in Chrome.
4. Phone: menu (3 dots) > Add to Home screen > Install. Desktop: install icon in the address bar.

Progress is saved in the browser you use, so open it in the same place each time.
